# OpenChats

All-in-one chatting website for teams. Your teams, your conversations, one place.

</div>

## Tech Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- [Tailwind CSS v4](https://tailwindcss.com)
- [Convex](https://convex.dev), [Stream Chat](https://getstream.io/chat/), [Better Auth](https://better-auth.com)
- Deployed on [Cloudflare](https://workers.cloudflare.com) via [OpenNext](https://opennext.js.org)
